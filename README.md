# The Wire - Fan Site 
Este projeto é um site estático dedicado à aclamada série de TV "The Wire" (A Escuta), explorando sua história, temporadas e personagens principais. O desenvolvimento foi feito utilizando exclusivamente a linguagem de marcação HTML5, aproveitando todos os seus recursos semânticos e visuais nativos, sem qualquer uso de estilização externa ou CSS.

📁 Estrutura do Projeto
/ -> Contém este README.md.

/html/ -> Abriga as páginas (index.html, personagens.html e contato.html).

/img/ -> Destinado aos arquivos de imagem utilizados no site (pôsteres e fotos dos personagens).

/audio/ -> Destinado aos arquivos sonoros (ex: trilha de abertura clássica da série).


🛠️ Características do Projeto
Navegação: 3 páginas interligadas por um menu <nav> presente no cabeçalho de todos os arquivos.

Estrutura Semântica Completa: Uso nativo de marcações modernas como header, nav, main, section, article, aside e footer para organizar o conteúdo sobre o universo de Baltimore.

Tabelas de Dados: A página de personagens apresenta um guia completo das 5 temporadas usando uma tabela organizada de forma nativa.

Formulário de Fã-Clube: A página de contato coleta preferências dos usuários sobre a série utilizando atributos dinâmicos do HTML5, como seleção de datas, barra de alcance (range), envio de fanarts e caixas de seleção com autocompletar (datalist).

Interatividade Nativa: Tags <details> e <summary> empregadas para ocultar/exibir sinopses e curiosidades sobre personagens como Omar Little, sem necessidade de JavaScript.

Mídia Estruturada: Uso de <figure> e <figcaption> para exibir e legendar imagens, além de um player de áudio integrado com a tag <audio controls> para tocar a música tema.

Marcação de Texto Rico: Destaques na narrativa utilizando tags semânticas como <abbr>, <mark>, <del>, <ins>, citações com <blockquote> e <cite>, além de medidores nativos como <progress> e <meter> para ilustrar o impacto cultural da série.

🚀 Como Executar
Baixe os arquivos do projeto para sua máquina local mantendo a estrutura de pastas.

Adicione imagens de The Wire na pasta /img e um arquivo de música na pasta /audio com os mesmos nomes definidos no código-fonte.

Abra o arquivo index.html diretamente em qualquer navegador web. Não é necessário servidor local ou instalação de dependências.
